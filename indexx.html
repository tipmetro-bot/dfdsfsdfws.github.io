На каких версиях работает?

Minecraft 1.21.4, Fabric Loader + Fabric API, Java 21.

Не запускается / чёрный экран?

Fabric точно 1.21.4, Fabric API в mods/, старые voidDLC из mods/ удалить — остаётся один jar.

ServerGuard надо настраивать?

Нет. Обычные серверы — безопасный профиль; FunTime, SpookyTime, ReallyWorld, HolyWorld — хардкор включается сам.

Где настройки?

.minecraft/config/voidDLC/: конфиг, binds.json, профили отдельными JSON. Последний профиль грузится сам.

Почему свой шрифт?

VoidFont растеризует Inter/Rajdhani/Orbitron сам, в native-разрешении — текст всегда чёткий.
